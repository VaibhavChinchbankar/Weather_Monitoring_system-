# 🌦️ Weather Monitoring System

A machine learning-based weather monitoring and forecasting system developed using Python. The project uses historical weather data to train a machine learning model and provides weather predictions through a simple application interface.

## 📌 Project Overview

The Weather Monitoring System is designed to analyze weather-related data and predict weather conditions using a trained machine learning model.

The project consists of:

- A Python application (`app.py`)
- A weather dataset (`weather_forecast_data.csv`)
- A trained machine learning model (`weather_model.pkl`)

## 🚀 Features

- Weather data analysis
- Machine learning-based weather prediction
- Trained model stored using Pickle
- Simple application interface
- Prediction based on user-provided weather parameters
- Dataset-based model training

## 🛠️ Technologies Used

- **Python**
- **Machine Learning**
- **Pandas**
- **NumPy**
- **Scikit-learn**
- **Streamlit**
- **Pickle**
